# 国际化检查

检查项目中的国际化完整性，确保 zh-CN 和 en-US 语言文件同步。

## 检查范围

$ARGUMENTS

如果未指定范围，则检查整个项目。

## 执行步骤

1. 扫描 Vue 文件中的 `$t()` 和 `t()` 调用
2. 提取所有使用的翻译键
3. 对比 zh-CN 和 en-US 语言文件
4. 报告缺失的翻译键

## 检查位置

### 主应用语言文件
- `apps/web-antd/src/locales/langs/zh-CN/`
- `apps/web-antd/src/locales/langs/en-US/`

### 插件语言文件
- `apps/web-antd/src/plugins/*/langs/zh-CN/`
- `apps/web-antd/src/plugins/*/langs/en-US/`

### 全局语言文件
- `packages/locales/src/langs/zh-CN/`
- `packages/locales/src/langs/en-US/`

## 输出格式

### 📊 检查结果

| 状态 | 数量 |
|------|------|
| ✅ 已翻译 | X |
| ❌ zh-CN 缺失 | X |
| ❌ en-US 缺失 | X |

| 键 | 使用位置 |
|----|---------|

#### en-US 缺失
| 键 | 使用位置 |
|----|---------|
