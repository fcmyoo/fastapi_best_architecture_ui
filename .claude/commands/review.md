# 代码审查任务

请对当前分支的代码变更进行全面审查。

## 审查范围

$ARGUMENTS

如果未指定范围，则审查当前分支相对于 master 的所有变更。

## 执行步骤

1. 运行 `git diff master...HEAD --stat` 查看变更文件列表
2. 运行 `git diff master...HEAD` 查看详细变更
3. 逐文件进行审查

## 审查清单

### 代码质量
- [ ] 代码是否符合项目 ESLint/Prettier 规范
- [ ] 命名是否清晰准确（变量、函数、组件）
- [ ] 逻辑是否简洁高效
- [ ] 是否遵循 SOLID、DRY、KISS 原则

### Vue/TypeScript 规范
- [ ] 组件是否使用 `<script setup lang="ts">`
- [ ] Props 是否正确定义类型
- [ ] 响应式数据是否正确使用 ref/reactive
- [ ] 是否正确使用 computed 和 watch
- [ ] 是否有内存泄漏风险（事件监听、定时器）

### 安全检查
- [ ] 是否存在 XSS 漏洞（v-html 使用）
- [ ] 是否存在敏感信息硬编码
- [ ] API 调用是否有适当的错误处理
- [ ] 权限校验是否完整

### 国际化
- [ ] 新增文本是否使用 $t() 包裹
- [ ] 是否同时更新 zh-CN 和 en-US 语言文件

### 性能
- [ ] 是否有不必要的重渲染
- [ ] 大列表是否使用虚拟滚动
- [ ] 图片是否懒加载
